# Minecraft Browser Sandbox · 1.6.0

Replace your repository’s **index.html** with this update. Keep the extracted **SFX/** and **Music/** folders beside it, with filenames and subfolders unchanged. Icons, fonts and code are embedded.

**What changed:** combat hit boxes and cooldowns; room-join retries; accurate held items, armor and forward Elytra poses; rocket boosts; voice playback; smoother jumping/landing and damage tilt; connected ore veins; cloud skins, usernames, linked Google/email sign-in and private groups. Full patch notes are in the game.

**Publish the new firestore.rules in Firebase**, following **FIREBASE-SETUP.md**. Uploading rules to GitHub alone does not enable cloud features. Your Firebase configuration and automatic TURN relay are included.

Everyone joining a room needs **1.6**. Keep the host open. In an Online room, enable your microphone under **Players → Voice chat**. If voices are silent, press **Resume voice playback** and check its status.

**Controls:** WASD move · Space jump · Shift crouch · R sprint · E inventory · T chat · Tab complete commands · F5 camera · V push to talk · Esc menu. Change bindings in Options.

Existing saves and imported backups remain compatible. Export a backup before updating and retain the same website address. Old worlds keep their terrain. Create a new default world for the dirt/air layout and ores; superflat is unchanged.

Usernames change once every **7 weeks**; display names change freely. Friends use usernames or stable friend codes. Groups support **2–8 people**. Skins sync when signed in; world saves need exported backups to move devices.

**Minecraft-source.zip** contains editable source and licenses, excluding large sound/music folders. This is an independent, simplified voxel recreation.
